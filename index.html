SURVIVOR FIELD MANUAL / REV. 01

Know what follows you.

01 / THE GRID

Carry the light.

Collect amber power cells with E. Carry up to two. Return to the central station and press E to install them. Once powered, reach the south extraction zone. Finish three operations to escape.

02 / THE DARK

They cannot see you.

In darkness, infected cannot visually acquire you. They can still hear footsteps, engines, and gunfire, follow nearby blood, or remember your last position. F toggles your flashlight. The station perimeter protects survivors; new AI infected arrive elsewhere when one is killed.

03 / THE BITE

No going back.

A bite starts a 75-second transformation. Trauma kits heal wounds, not infection. After turning, use BITE to hunt. If survivors shoot an infected player down, they reanimate as infected after eight seconds. Killed AI infected are replaced to keep the district dangerous.

04 / THE MEMORY

Habits have a cost.

Infected adapt to aggregate gunfire, light use, and time. Observed human traffic influences patrols; later tiers enable flanking and longer pursuit. This is bounded game AI, not a language model.

HOSTING / PLAYTEST CONFIGURATION

How this city stays online.

01 / THIS HOST

Up to five live operations.

The public playtest uses one Render Free web service. The server accepts up to five operations with up to 15 players each. Player graphics render on each device. A free instance can sleep or restart, and five busy rooms may exceed its CPU or memory; this cap is a best-effort playtest limit, not a capacity guarantee.

02 / YOUR DEVICE

Graphics stay local.

Each player renders the world on their own phone, tablet, or computer. The host runs game rules and shares room state. Joining a game never turns your device into a server.

03 / SELF HOST

Run your own match server.

With the project and Node.js 24, run npm ci, npm run build, then npm start. Set MAX_ROOMS to the capacity you plan to test. A software limit is not a tested player capacity.

04 / SERVICE NOTES

Playtest, not production.

Room codes are join links, not passwords. Match state is temporary. The game currently has no account system, persistent profiles, or friends list.
